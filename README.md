# Food Safety Path

Crea un curso interactivo de manipulador de alimentos con diseño visual amable y didáctico. El contenido teórico es fijo y no debe modificarse. El curso se estructura en 6 módulos, cada uno con su contenido teórico, y al final de cada módulo debe haber un test de evaluación (opción múltiple o verdadero/falso) que se puede repetir tantas veces como sea necesario, guardando el progreso. Para avanzar al siguiente módulo, el usuario debe aprobar el test con al menos un 80% de aciertos. Al completar y aprobar los 6 módulos, se debe emitir automáticamente un certificado de manipulador de alimentos otorgado por la "Asociación de Empresarios de Hostelería Álvaro Cunqueiro".

Los módulos son:

1. Marco legal, responsabilidades y cultura de seguridad alimentaria

2. Peligros y contaminación de los alimentos (biológica, química, física y cruzada)

3. Enfermedades de transmisión alimentaria (ETAs)

4. Higiene personal del manipulador y buenas prácticas

5. Limpieza, desinfección, conservación y cadena de frío

6. Alérgenos, trazabilidad, nociones de APPCC + evaluación final

Diseña el sitio web del curso con un enfoque visual claro, atractivo y fácil de seguir. Incluye imágenes representativas para cada módulo y para la interfaz general, que refuercen visualmente los temas tratados (por ejemplo, iconos de alimentos, utensilios limpios, cadenas de frío, alérgenos, etc.). La navegación debe ser intuitiva, mostrando el progreso del usuario y permitiendo retomar el curso donde lo dejó. El certificado final debe tener un diseño profesional con el nombre del usuario, la fecha de finalización y el logotipo de la asociación mencionada. No alteres el contenido teórico en ningún caso.
